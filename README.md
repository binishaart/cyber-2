Cyber-Threat Intelligence Portal

A Flask-based web portal that visualizes emerging cyber threats from forums and public sources using interactive charts in the browser.

📝 Description

This hackathon-ready web app provides a real-time view of cyber threats like malware, phishing, ransomware, zero-day exploits, and botnets. The dashboard uses Chart.js for interactive bar charts, delivering a lightweight, responsive, and visually appealing overview of threat trends.

💡 Features

Interactive dashboard showing emerging cyber threats

Lightweight and fully compatible with Python 3.14

Browser-based bar charts using Chart.js (no Python plotting libraries required)

Clean, dark-themed UI for better readability

Easy deployment with Gunicorn (Render/Heroku)
